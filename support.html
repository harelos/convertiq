⚡ Get started in 60 seconds

1

Install the extension

Click Add to Chrome on the Chrome Web Store. The extension installs in seconds — no account required.

2

Get your Anthropic API key

Go to console.anthropic.com → API Keys → Create Key. The key starts with sk-ant-api03-. Anthropic offers free credits for new accounts.

3

Connect your key

The ConvertIQ settings page opens automatically on first install. Paste your API key → Save Key → Test Connection. ConvertIQ confirms the key works before you use it.

4

Run your first audit

Navigate to any SaaS landing page. Click the ◆ ConvertIQ icon in your Chrome toolbar. Click "Analyze This Page." Your CRO score appears in ~10 seconds.

Each ConvertIQ audit uses Claude Sonnet and costs approximately $0.01–$0.03 per audit depending on page length. At 5 audits/day, that's under $5/month in API costs — and Anthropic gives new accounts free credits. Pro users running 20+ audits/day might spend $10–$20/month in API costs.
When you click Analyze, ConvertIQ sends the following to Anthropic's API:
  • The page headline, subheadings, and button text
  • A 1,000-character text sample from the page body
  • Structural signals (does it have testimonials, pricing, FAQs, etc.)
ConvertIQ has no backend — this data goes directly from your browser to Anthropic. We never see it. See our Privacy Policy for full details.
