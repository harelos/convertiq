Privacy Policy

Last updated: March 19, 2025 · Effective immediately

The short version: ConvertIQ collects no personal data, has no backend server, and stores nothing outside your own browser. Your Anthropic API key is stored locally in Chrome and sent only to api.anthropic.com when you click Analyze. That's it.

1. Who We Are

ConvertIQ ("we," "us," or "our") is a Chrome browser extension that analyzes SaaS landing pages for conversion rate optimization (CRO). This Privacy Policy describes how ConvertIQ handles information when you use the extension and this website.

If you have questions, contact us at: privacy@convertiq.app

2. Information We Do NOT Collect

ConvertIQ is designed from the ground up to collect no personal information. Specifically, we do not collect:

  • Your name, email address, or any account information
  • Your browsing history or the URLs of pages you visit
  • Your Anthropic API key (it is stored only in your browser's local storage)
  • The content of pages you analyze
  • Your IP address or location
  • Usage analytics or behavioral data
  • Crash reports or diagnostic data
  • Payment information (handled entirely by our payment processor)

ConvertIQ has no backend server that receives or stores your data. There is no database. There are no user accounts.

3. What Stays in Your Browser

The following data is stored exclusively in your browser using Chrome's chrome.storage.local API. It never leaves your device except as described in Section 4:

  • Anthropic API key — stored encrypted in Chrome local storage, used only to call Anthropic's API on your behalf
  • Audit results cache — CRO analysis results are cached for 24 hours per URL to avoid redundant API calls
  • Daily usage count — a counter that resets each day, used to enforce the free tier limit (5 audits/day)
  • User plan status — "free" or "pro," stored locally after plan verification

You can clear all locally stored data at any time by removing the extension from Chrome or by clearing extension data in Chrome's settings (chrome://settings/content/all).

4. Data Sent to Third-Party Services

When you click "Analyze This Page," ConvertIQ sends the following data to Anthropic's API on your behalf:

  • Extracted page content: headline, subheadings, button text, meta description, and a text sample (up to 1,000 characters)
  • Structural signals: whether the page has testimonials, pricing sections, FAQ, trust badges, etc.
  • Your API key (in the request header, to authenticate the request)

This data is transmitted directly from your browser to api.anthropic.com. ConvertIQ never sees, stores, or logs this data. Anthropic's handling of data sent to their API is governed by Anthropic's Privacy Policy.

Important: Do not use ConvertIQ to analyze pages containing sensitive personal information (PII, health records, financial data, etc.). The page content extraction and AI analysis is designed for public-facing marketing pages only.

5. Chrome Extension Permissions

ConvertIQ requests only the minimum permissions required to function:

  • activeTab — allows the extension to read the URL and inject a content script into the currently active tab when you click Analyze. The extension cannot read other tabs.
  • storage — allows the extension to store your API key, usage count, and cached results in Chrome's local storage.
  • scripting — allows the extension to inject a content extraction script into the active tab when you click Analyze. This script extracts text content and returns it to the extension. It does not modify the page.

ConvertIQ does not request host_permissions, <all_urls>, or broad browsing history access. Content scripts are injected only on explicit user action (clicking "Analyze This Page"), not automatically on page load.

6. Website Analytics

This website (convertiq.app) does not use any analytics, tracking pixels, or cookies beyond what is technically required to serve the pages. We do not use Google Analytics, Facebook Pixel, or any third-party tracking tools.

GitHub Pages (our hosting provider) may collect basic server logs (IP addresses, request timestamps) as part of standard web server operation. This is governed by GitHub's Privacy Policy.

7. Payments and Pro Plan

If you upgrade to ConvertIQ Pro, payment is processed by a third-party payment processor (Stripe or LemonSqueezy). We do not store or handle your payment card information. All payment data is governed by the payment processor's privacy policy.

Upon successful payment, your plan status ("pro") is stored locally in your browser. We may store your email address for the purpose of managing your subscription and sending transaction receipts.

8. Children's Privacy

ConvertIQ is not directed at children under the age of 13. We do not knowingly collect any personal information from children. If you believe a child has provided personal information, please contact us at privacy@convertiq.app.

9. Your Rights

Because we collect no personal data, there is generally nothing to access, correct, or delete. However:

  • You can delete all locally stored data by removing the extension
  • If you have a Pro subscription, you can request deletion of your email from our subscription records by contacting privacy@convertiq.app
  • California residents: ConvertIQ does not sell personal information and is therefore not subject to CCPA opt-out requirements
  • EU/UK residents: our processing of any personal data (subscription email only) is based on contract performance (GDPR Article 6(1)(b))

10. Data Security

ConvertIQ is architected so that sensitive data (your API key) never passes through any server we control. The only external transmission is directly from your browser to Anthropic's API over encrypted HTTPS. Chrome's storage.local API is sandboxed to the extension and is not accessible by websites.

11. Changes to This Policy

We may update this Privacy Policy from time to time. Material changes will be noted with an updated "Last updated" date. Continued use of the extension after changes constitutes acceptance. We will not reduce your privacy protections without explicit notice.
